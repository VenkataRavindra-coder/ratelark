Markup e margem não são a mesma coisa

Markup é o lucro como porcentagem do custo. Margem é o lucro como porcentagem do preço de venda. Um markup de 50% sobre um custo de $40 resulta em um preço de $60, que é apenas uma margem de 33,3%.

Qual devo usar para precificar um trabalho?

Use o markup se você parte do custo e soma uma porcentagem. Use a margem se quer que o lucro seja uma parcela fixa do que o cliente paga. Confundir os dois é um jeito fácil de cobrar menos do que deveria.
